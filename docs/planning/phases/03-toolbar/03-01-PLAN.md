## Plan: EncryptionBarStateMachine + SecurePrefs

Create the dual-lock state machine and secure preferences namespace — pure logic, no UI dependency.

### Files to Create

1. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/input/bar/EncryptionBarStateMachine.kt`**

   Dual-lock state machine following `KawaiiBarStateMachine` pattern:
   - 4 states: `UNLOCKED, LOCKED, ENCRYPTING, ENCRYPTED`
   - BooleanKeys: `BufferEmpty` (tracks whether Buffer Bar has content)
   - TransitionEvents:
     - `LockToggled` — UNLOCKED ↔ LOCKED (mutual toggle; encrypt lock on → off decrypt lock)
     - `DecryptToggled` — UNLOCKED → LOCKED in decrypt mode (green)
     - `EncryptRequested` — LOCKED → ENCRYPTING (when buffer has content)
     - `EncryptionCompleted` — ENCRYPTING → ENCRYPTED
     - `SendRequested` — ENCRYPTED → UNLOCKED (clear buffer, reset)
     - `EditRequested` — ENCRYPTED → LOCKED (back to editable)
     - `BufferUpdated` — tracks BufferEmpty boolean state changes
   - `new()` factory method with `onNewStateListener` callback
   - Follow exact pattern from `KawaiiBarStateMachine.kt`: `object EncryptionBarStateMachine`, `enum class State`, `enum class BooleanKey`, `enum class TransitionEvent` with `BuildTransitionEvent` delegates

2. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/data/prefs/AppPrefs.kt`** (edit existing)

   Add `Secure` inner class inside `AppPrefs`:
   - `inner class Secure : ManagedPreferenceCategory(R.string.secure, sharedPreferences)`
   - Fields (all follow ManagedPreference pattern):
     - `lockState` — string("lock_state", "UNLOCKED") — stores enum name
     - `encryptMode` — string("encrypt_mode", "CODEBOOK") — current encryption mode
     - `selectedContactIds` — string("selected_contact_ids", "") — comma-separated IDs (Phase 4 fills in)
     - `codebookId` — string("codebook_id", "default") — current codebook identifier
     - `bufferContent` — string("buffer_content", "") — Buffer Bar text content
   - Register: add `val secure = Secure().register()` alongside existing `val clipboard = Clipboard().register()` line
   - Add `R.string.secure` string resource in `res/values/strings.xml`

3. **`fcitx5-android/app/src/main/res/values/strings.xml`** (edit existing)

   Add `<string name="secure">加密</string>` entry

### Key Patterns to Follow

- **State machine**: See `KawaiiBarStateMachine.kt` — `object`, `enum class State`, `enum class BooleanKey`, `enum class TransitionEvent(val builder: TransitionBuildBlock<...>) : EventStateMachine.TransitionEvent<...> by BuildTransitionEvent(builder)`, factory `fun new(block)`
- **Prefs**: See `Clipboard` inner class in `AppPrefs.kt` — `inner class Xxx : ManagedPreferenceCategory(R.string.xxx, sharedPreferences)`, fields use `bool/string/int/switch`, then `.register()` at class level
