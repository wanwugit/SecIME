## Plan: EncryptionBarComponent + BufferBarUi + SlotView + InputView Integration

Build the encryption toolbar UI layer: component, Buffer Bar, slot placeholders, and wire into InputView.

### Files to Create

1. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/input/bar/EncryptionBarComponent.kt`**

   Component following `UniqueViewComponent` pattern:
   - `class EncryptionBarComponent : UniqueViewComponent<EncryptionBarComponent, FrameLayout>()`
   - DI dependencies via `manager.must<>()`: `InputDecisionBus`, `KawaiiBarComponent` (for coordination)
   - Internal state machine: `EncryptionBarStateMachine.new { onStateChanged(it) }`
   - `view` by lazy: FrameLayout containing the candidate area (BufferBarUi + slots)
   - Default `visibility = GONE`
   - Public methods:
     - `fun toggleEncryptLock()` — push LockToggled to state machine, show/hide view
     - `fun toggleDecryptLock()` — push DecryptToggled to state machine, show/hide view
     - `fun onBufferContentChanged(text: String)` — update BufferBarUi, push BufferUpdated
     - `fun requestEncrypt()` — push EncryptRequested (Phase 5 adds actual crypto call)
     - `fun requestSend()` — push SendRequested, commit encrypted text
     - `fun requestEdit()` — push EditRequested, return to editable state
   - `companion object { const val HEIGHT = 40 }` — matches KawaiiBar height
   - `onScopeSetupFinished`: read SecurePrefs, restore lock state if not UNLOCKED

2. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/input/bar/ui/BufferBarUi.kt`**

   Splitties DSL UI following `IdleUi.kt` / `CandidateUi.kt` pattern:
   - `class BufferBarUi(override val ctx: Context, private val theme: Theme) : Ui`
   - Root: horizontal `constraintLayout` with:
     - Left: lock icon (ImageView, 20dp) + text preview (TextView, scrollable horizontal, max 1 line, ellipsize END)
     - Right: char count label (TextView, e.g. "12/200") + delete button (ImageView, 20dp, trash icon)
   - Color theming per spec §8.3:
     - `fun setEncryptMode()` — purple border (#7C4DFF), light purple background (#F3E5F5), purple text (#7C4DFF), purple lock icon
     - `fun setDecryptMode()` — green border (#4CAF50), white background, green text (#4CAF50), green lock icon
   - Public methods:
     - `fun updateContent(text: String)` — update preview text + char count
     - `fun clearContent()` — reset to empty
   - Height: 24dp (within the 40dp toolbar, leaving room for slots)
   - Border: 1dp stroke rounded rectangle (use ShapeDrawable or card with stroke)

3. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/input/bar/ui/SlotBarUi.kt`**

   Slot placeholder row following spec §8.4:
   - `class SlotBarUi(override val ctx: Context, private val theme: Theme) : Ui`
   - Root: horizontal `LinearLayout` with 4 equal-width slots
   - Each slot: `TextView` with:
     - Dashed border (gray #808080, 1dp dash, 2dp gap) via ShapeDrawable
     - Text: "+" in Empty state, gray 11sp centered
     - Width: 0dp with weight=1 (equal width)
     - Height: 16dp
     - Margin: 2dp horizontal between slots (4dp gap total)
   - `fun setSlotState(index: Int, state: SlotState, label: String = "")` — update slot visual
   - `enum class SlotState { Empty, Idle, Active }` — three states per spec §8.4
   - Click listeners: `var onSlotClick: ((index: Int) -> Unit)? = null` — Phase 4 fills in
   - Active state: solid border with theme color, theme color text

4. **`fcitx5-android/app/src/main/java/org/fcitx/fcitx5/android/input/bar/ui/EncryptionCandidateUi.kt`**

   Container combining BufferBarUi + SlotBarUi:
   - `class EncryptionCandidateUi(override val ctx: Context, private val theme: Theme) : Ui`
   - Root: vertical `LinearLayout`
     - Top: `BufferBarUi` (24dp)
     - Bottom: `SlotBarUi` (16dp)
   - Total height: 40dp (matches EncryptionBarComponent.HEIGHT)
   - Delegates content/color updates to BufferBarUi
   - Delegates slot updates to SlotBarUi

### Key Patterns to Follow

- **Component**: See `KawaiiBarComponent.kt` — `UniqueViewComponent<T, V>`, `manager.must<>()` for DI, `view by lazy` for ViewAnimator/FrameLayout
- **UI**: See `IdleUi.kt` — `class XxxUi(override val ctx: Context, ...) : Ui`, Splitties DSL for layout construction
- **Layout integration**: See `InputView.kt` lines 259-284 — `add(view, lParams(width, height) { below/above constraints })`
- **ToolButton**: See `ToolButton.kt` in `bar/ui/` — custom button class used in toolbar
